# Reproducibility verification of v2.1.2-r0

2 November 2026. Fresh processed-input fitting, model selection, evaluation, 5,000-draw bootstraps and MSE calculations were executed for all twelve requested stages from `/private/tmp`, with a fresh output directory outside the package. The existing isolated Python 3.9.6 virtual environment was reused, with user site packages disabled and installed versions checked against the lock file. A new environment installation is not claimed for this run.

The independent verifier passed **1,110 assertions**, comparing **4,137,623 numerical cells** against the corrected evidence, including prediction tables, calibration/selection results, MSE closure and independent within-/between-hour covariance calculations. Deliberately stale-count and altered-covariance controls were rejected. Calibration-only fitting and the frozen model check before 2026 evaluation remained intact.

All six figures were regenerated from these fresh results and packaged fixed-design/native assets. Their PNG pixels match the current manuscript figure references. The wide Figure 5 layout and Figure 6 panel labels/dark-green outlines are reproduced by the traced portable figure code. Figure 6 native-array hashes match their retained source arrays. PNG file metadata/compression can differ without pixel differences.

The strict-quality analysis and paired 5,000-draw sensitivity were rerun with the newly fitted calibration models: 11,123 numerical cells matched. Modern station reconstruction passed all four table comparisons for 282 pairs (173 in 2025; 109 in 2026), with maximum numeric discrepancy 1.33e-15. These are offline station-pair and retained-neighborhood reconstructions, not new decoding of bulk provider files.
