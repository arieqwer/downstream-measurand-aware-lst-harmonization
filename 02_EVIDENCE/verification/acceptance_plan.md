# Independent acceptance plan — 29 October 2026

Scope is a consistent calendar and full-polygon extraction repair throughout the existing manuscript's calibration and evaluation pipeline. Units remain K, with the saved city-area core/ring polygons, original quality masks, source files, support thresholds, candidates, split logic and bootstrap rules. Scientific outputs are isolated; no Word integration is authorized in this phase.

1. Freeze original file hashes; compare original pipeline replay with archived numerical baselines before evaluating repaired outputs. Original artifacts must remain immutable.
2. Independently enumerate native pixel centres over the entire actual grid and saved polygons, using a polygon implementation different from the extractor. Corrected masks must contain all native centres strictly inside their saved polygon, with no fixed-radius clipping. Compare arrays/counts for every city/platform/dataset geometry; report zero-support cases explicitly.
3. Check calendar by independent civil-timezone and fixed-offset constructions, local sunset date and exact sunset timestamp. Cover all request city/date pairs; include summer/year boundary and DST controls. Target acquisition inventory hours must equal nearest hour of sunset plus the declared target-hour bin; requested and actual scan times must remain distinct. No missing key may be filled with a fallback acquisition under the original requested hour.
4. Calendar reallocation must assign each physical sunset date to the original declared interval, with correct event IDs and no duplicate city/date/hour rows. Native missing objects and failed requests must be counted separately. Cached source rows can be reused only if their geometry, packing/mask semantics, source time and observation identity are independently unchanged.
5. Decode representative native files with an independent CF implementation; independently recompute complete-polygon regional means/counts for changed masks and newly extracted boundaries. Check historical unsigned packing and historical bitmask versus modern categorical DQF semantics. Preserve exact original valid-data rule unless the repair explicitly addresses a newly found error.
6. Independently reconstruct paired daily support, equal-day city–interval–hour means, and pre/post transitions; compare counts, means, scan separation, missingness and cohort membership. Quality sensitivity must distinguish common support from changed pixel means.
7. Candidate families, hyperparameters, calibration cities/intervals, cross-validation splits, one-SE rule, selection scoring, seeds and inference clusters must be the original protocol. Refit only on repaired calibration; freeze the model before reading 2026 evaluation. No 2026-driven candidate changes or threshold tuning.
8. Independently verify final prediction algebra, correction offsets, population MSE budgets and derived contrast/transition metrics. Reconstruct saved bootstrap draws from row weights for representative seeds and verify all percentile summaries. Percent RMSE and percent MSE changes must be labeled distinctly.
9. Final acceptance is per issue: numerical execution/replay, complete polygon support, local calendar correctness, consistency across affected stages, protocol preservation and immutable originals. A scientific issue is not resolved merely because a program exits zero. Ground validation and historical LHP attribution remain distinct previously reported limitations.

All verifier scripts and evidence are confined to this verification directory. Thresholds: native CF mean replay ≤1e−4 K (float precision), independent aggregate/prediction/MSE numerical replay ≤1e−9 in corresponding units; exact native counts/keys/cohort identities; date membership exact. Any amendment must retain earlier evidence and explain the change.
